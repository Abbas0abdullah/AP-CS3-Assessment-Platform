## 💎 نبذة عن المنصة
تم تصميم وتطوير هذه المنصة الأكاديمية الفاخرة بأعلى معايير تجربة المستخدم وتصميم الويب الحديث (Dark Luxury / Obsidian Gold)، بعيداً تماماً عن القوالب الجاهزة أو الـ AI Slop، لتوفر لطلاب ومهندسي الحاسوب بيئة اختبار وتدريب تفاعلية واقعية بنسبة 100%.

تحتوي المنصة على **465 سؤال اختيار من متعدد (MCQ)** مستخرجة بدقة كاملة من ملفات بنك الأسئلة المعتمدة، مع الإجابات النموذجية والتفسيرات العلمية.

## 🎯 المميزات الرئيسية
1. **تخصيص كامل للاختبار**:
   - **اختيار المحاضرات / السلايدات المستهدفة**: يمكنك اختيار محاضرة واحدة أو عدة محاضرات معاً:
     - **المحاضرة 1 (97 سؤالاً)**: بيئة .NET، CLR، أساسيات الكينونية ومبادئ SOLID الخمسة (SRP, OCP, LSP, ISP, DIP).
     - **المحاضرة 2 (80 سؤالاً)**: مشاكل التصميم السيء، تاريخ Gang of Four، والأنماط الإنشائية (Singleton & Factory Method).
     - **المحاضرة 3 (100 سؤال)**: الأنماط الهيكلية (Adapter, Facade, Proxy, Decorator) وعلاقات UML والتشبيهات الواقعية.
     - **المحاضرة 4 (80 سؤالاً)**: الأنماط السلوكية (Strategy & Observer) ومصفوفة مقارنة الأنماط وربطها بمبادئ SOLID.
     - **المحاضرة 5+6 (108 أسئلة)**: معمارية البرمجيات، المعمارية النظيفة Clean Architecture بطبقاتها الأربع وبيئة ASP.NET Core وحقن التبعيات DI.
   - **تحديد عدد الأسئلة**: أزرار سريعة (10، 20، 30، 50، أو الكل) مع شريط سحب ذكي (Slider) لتحديد أي رقم تريده بدقة.
   - **الترتيب العشوائي**: خيار عشوائية ترتيب الأسئلة + خيار خلط أماكن خيارات الإجابة (A, B, C, D) لضمان الفهم الحقيقي وليس حفظ الترتيب.

2. **أنماط الاختبار المتطورة**:
   - 🎓 **وضع الاختبار الأكاديمي (Exam Mode)**: بيئة تحاكي الامتحانات النهائية، مع مؤقت زمني دقيق وشبكة تنقل سريعة بين الأسئلة، ولا تظهر الإجابات إلا عند تسليم الاختبار.
   - ⚡ **وضع التدريب الفوري (Practice Mode)**: ظهور الإجابة النموذجية فور اختيارك مع بطاقة تفسير علمي دقيقة ومؤثرات صوتية محفزة.

3. **حساب النسبة المئوية والتحليلات البيانية**:
   - عدّاد نسبة مئوية متحرك بدقة عشرية (مثل: `94.5%`).
   - مقياس دائري SVG متدرج بالألوان الفاخرة (Gold, Cyan, Emerald).
   - رتبة ودرجة التقييم (درجة الامتياز 🏆، مستوى متقدم ⭐، مقبول 📖...).
   - تفصيل النسبة المئوية لكل محاضرة على حدة لمعرفة نقاط القوة والضعف.
   - احتساب وقت الاختبار والوقت المتوسط لكل سؤال.
   - احتفالية Confetti متحركة عند تحقيق درجة تفوق (80%+).

4. **نظام مراجعة الأخطاء الذكي**:
   - فلترة الأسئلة بعد انتهاء الامتحان: (عرض الكل / الخاطئة فقط / الصحيحة فقط / المميزة بنجمة).
   - زر **"إعادة محاولة الأخطاء فقط"**: يتيح لك إعادة خوض اختبار يركز حصراً على الأسئلة التي أخطأت بها لترسيخها.

5. **بنك الأسئلة الشامل (Searchable Bank)**:
   - محرك بحث فوري بالكلمات المفتاحية (مثل: `Singleton`, `SOLID`, `Repository`, `DIP`).
   - تصفح الأسئلة مع الحلول والتفسيرات دون الحاجة لبدء اختبار.

6. **مؤثرات صوتية تفاعلية وتصميم فاخر**:
   - نظام صوتي مبني داخلياً باستخدام Web Audio API (بدون ملفات خارجية تسبب بطء أو انقطاع).
   - اختصارات لوحة المفاتيح: الأرقام (1, 2, 3, 4) أو الحروف (A, B, C, D) للاختيار، والأسهم للتنقل، و F للتمييز.
   - دعم الوضع الليلي الفاخر (Dark Luxury) والوضع النهاري (Light Mode).
